# FlyRank Polite Scraper (Assignment A9)

A structured, polite web scraping pipeline built in Node.js that scrapes the first 3 catalogue pages of Books to Scrape, validates the extracted records with Zod, and exports a run summary report.

## Target Classification
- **Target Site:** `https://books.toscrape.com/`
- **Purpose:** Educational sandbox explicitly built for practice web scraping.
- **Scope:** First 3 catalogue pages only (60 books total).
- **Data Collected:** Book title, product URL, price, availability, rating, and description.
- **Robots.txt Result:** No `robots.txt` found (HTTP 404).
- **Ethics & Politeness Commitment:** "I will not reuse this code on another site without checking its rules and terms first."
